# nigutime 遊戲設計文件

**日期：** 2026-04-22  
**專案：** nigutime — 大悲咒木魚敲擊遊戲

---

## 概述

一個網頁遊戲，玩家在聆聽大悲咒的同時，敲擊隨機出現的木魚累積「功德值」。遊戲難度隨分數遞增，大悲咒播放速度也同步加快，形成荒謬的佛系迷因體驗。玩家結束後可以輸入法號上傳至全球功德排行榜。

---

## 技術架構

- **Frontend**: Next.js 14 (App Router) + Tailwind CSS
- **Backend/DB**: Supabase (PostgreSQL + Realtime subscriptions)
- **音效**: 大悲咒音頻 + 木魚敲擊音效放在 `/public`，透過 Web Audio API 播放與控速（音頻檔需自行準備，建議使用公開授權版本）
- **部署**: Vercel + 使用者自訂網域

---

## 頁面結構

### 1. 首頁 (`/`)
- 遊戲標題與簡短說明
- 「開始念經」按鈕 → 進入遊戲畫面
- 「功德排行榜」入口 → 顯示排行榜 modal（不離開首頁）

### 2. 遊戲畫面 (`/play`)
- 背景播放大悲咒（自動開始）
- 木魚隨機出現於螢幕各位置
- 右上角顯示「功德值：XX」
- 「功德圓滿」按鈕 → 結束遊戲並進入結算畫面

### 3. 結算畫面 (`/result`)
- 顯示本次功德值總分
- 輸入法號（暱稱）欄位，placeholder：「請輸入您的法號」
- 「上傳功德」按鈕 → 提交至排行榜
- 提交後自動跳轉至排行榜，並 highlight 自己那筆

## 遊戲機制

### 難度遞增系統

| 功德值區間 | 同時木魚數 | 出現間隔 | 大悲咒速度 |
|-----------|-----------|---------|----------|
| 0–9       | 1 個      | 2–4 秒  | 1x（正常）|
| 10–29     | 2 個      | 1.5–3 秒 | 1.3x    |
| 30–59     | 3 個      | 1–2.5 秒 | 1.6x    |
| 60+       | 4 個      | 0.5–1.5 秒 | 2x（快轉唸經）|

### 木魚行為
- 出現於螢幕隨機位置
- 敲擊後：播放木魚音效 + 震動/發光動畫 + 隨機跳出佛系文字
  - 浮動文字範例：「功德+1」、「業力清除中」、「佛祖按讚」
- 若超過 3 秒未敲，木魚自動消失（不扣分，僅錯過）
- 大悲咒速度達到 2x 時，畫面輕微抖動，提示文字顯示「法師超度加速中⚡」

## 視覺設計

**美學定位：表面莊嚴、內心荒謬（佛系迷因）**

- **背景**：深棕/暗金色調，古寺木牆質感
- **字體**：標題使用毛筆風格字體，文案內容荒謬有趣
- **木魚**：圓潤可愛圖示，敲擊時浮誇發光特效
- **分數**：顯示為「功德值：XX」
- **難度提示**：速度加快時顯示「法師超度加速中⚡」

## 排行榜

### Supabase `scores` 資料表

| 欄位 | 類型 | 說明 |
|------|------|------|
| `id` | uuid | 主鍵 |
| `nickname` | varchar(20) | 玩家法號 |
| `score` | integer | 功德值 |
| `created_at` | timestamp | 上傳時間 |

### 顯示邏輯
- 顯示前 20 名
- 使用 Supabase Realtime 訂閱，新分數上傳時自動更新（無需重新整理）
- 同分按 `created_at` 升序排列（先達到的排前面）
- 玩家上傳後，自動 highlight 自己那筆

### 防刷機制
- 同一個 browser session 只能上傳一次分數（client-side 防護，best-effort）
- 暱稱長度限制：最長 20 字
